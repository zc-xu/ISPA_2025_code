## Experiment Status

| Reviewer issue | Implementation and result |
|---|---|
| CLS initialization sensitivity | Five initialization strategies; 50 Random runs; fixed-130-user comparison plus `10/150` diagnostic. Random is generally consistent with dedicated initialization, while marginal Greedy can be substantially worse in the diagnostic case. |
| Two-stage optimality concern | Exact small-scale joint comparison for seeds `42` to `44`; Best Q gap is `0` for all three, while exact search requires about `4.99x` to `5.40x` the runtime. Kept as response evidence. |
| Learning-based baseline | Reproducible DQN baseline over seven distinct scale configurations; PSP has lower Best Q in every displayed configuration. |
| Hybrid anchor parameter | Capacity-aware anchor sweep retained for audit and future thesis work; manuscript uses the proportional interpretation. |
| Geographical generalization | Alternate real-region case with 40 candidates, 10 servers, 130 users, and 8 services; Stage-I CLS advantage is `62.53%`; PSP has the best three-seed mean HV and IGD. Kept as response evidence. |
| Pareto metrics | HV, IGD, and Best Q outputs are versioned with normalization evidence; DQN is compared by scalarized Best Q rather than represented as a misleading continuous Pareto population. |
