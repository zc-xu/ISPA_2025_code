## 3. DQN Restoration

The restored DQN treats Stage II as a finite sequential decision process. It receives server/slot progress, selected services, request distributions, deployment costs, and preference weight as input; it outputs a `K x 8` binary deployment matrix. The final matrix is evaluated by the original `MyServiceDeployProblem._calc_obj()`.

Formal settings:

- configurations: `10_100`, `10_130`, `10_150`, `10_180`, `5_130`, `15_130`, `20_130`;
- preference weights: `0.1, 0.3, 0.5, 0.7, 0.9`;
- DQN seed: 42;
- episodes: 320 per weight;
- service capacity: 4 per server;
- network: one hidden layer with 64 units, replay buffer, target network, epsilon-greedy exploration.

The representative 10/130 five-method results are:

| Method | HV | IGD | Spacing | BestQ | Pareto points |
|---|---:|---:|---:|---:|---:|
| PSP | 0.9582 | 0.0016 | 0.0107 | 0.3185 | 50 |
| DQN | 0.3382 | 0.4048 | 0.0097 | 0.5974 | 4 of 5 |

The conclusion is limited but consistent across all seven configurations: standard scalarized DQN is weaker than PSP under the declared budget. DQN points are not connected into a fake continuous curve.

## 5. Reproduce DQN

```powershell
git checkout dev
git pull origin dev
.\LocalSearch\Scripts\python.exe .\LocalSearch\dqn_service_baseline.py --configs all --weights 0.1 0.3 0.5 0.7 0.9 --episodes 320 --dqn-seeds 42

$configs='10_100','10_130','10_150','10_180','5_130','15_130','20_130'
foreach($config in $configs) {
    .\LocalSearch\Scripts\python.exe .\LocalSearch\pareto_batch_metrics.py --config $config
}
.\LocalSearch\Scripts\python.exe .\LocalSearch\plot_dqn_control_results.py
```

## 6. Excel Reproduction

Set `DQN_SOURCE_XLSX` to the original workbook and run the artifact-tool scripts with the bundled Node runtime. Then expand the native charts:

```powershell
$env:DQN_SOURCE_XLSX='C:\path\to\change_color_小论文实验二-user.xlsx'
$env:DQN_OUTPUT_DIR="$PWD\output\spreadsheet_dqn"
node .\tools\spreadsheet_dqn\update_workbook_with_dqn.mjs
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\spreadsheet_dqn\extend_excel_charts_with_dqn.ps1 -WorkbookPath .\output\spreadsheet_dqn\change_color_stage2_user_with_DQN.xlsx
```

The verified workbook has four charts on each of two experiment sheets, five points in every chart, and no formula errors.
