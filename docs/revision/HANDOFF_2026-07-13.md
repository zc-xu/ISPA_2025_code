DQN 被撤下是因为原先实现是普通标量化策略，只能在有限偏好权重下产生少量单点，不能与多目标算法生成的 Pareto set 作同等含义的曲线比较。SPEA2 不是 learning-based 方法，不能回应审稿人要求的 DRL/GNN 类服务放置基线。仓库只保留方法论复盘文档，不保留 DQN/SPEA2 的可运行代码和生成结果。

## 4. 新增实验结果

### 4.1 `varpi_j` 混合锚点敏感性

正式设计为 6 个数据配置、`V_j=4/8`、每个容量 4 个锚点设置、seeds 42/43/44、`pop_size=50`、`n_gen=200`，共 144 次 NSGA-II 运行。

结论边界：

- `varpi_j=V_j/2` 的含义清楚：一半容量用于确定性高分服务，一半保留随机探索。
- 半容量不是跨规模、跨容量的稳定最优值。`V_j=4` 的固定服务器实验线更偏向 `varpi_j=3`；`V_j=8` 中最优值随配置变化。
- 因此正文可以把半容量写成可解释默认折中，不能写成实验已证明其最优。

- `docs/revision/03_experiment_baselines/hybrid_anchor_sensitivity.md`
- `output/csv/hybrid_anchor_capacity_sensitivity_summary.csv`
- `output/csv/hybrid_anchor_capacity_sensitivity_detail.csv`
- `output/png/hybrid_anchor_capacity_sensitivity_cap4_10_130.png`
- `output/png/hybrid_anchor_capacity_sensitivity_cap8_10_130.png`

### 4.2 地理分布与流量泛化

合成实验生成 sparse-suburban、uniform-large、clustered-hotspot 三类场景。它们证明两阶段流程可在更宽、更稀疏或更异构的分布下完整运行并产生有效 Pareto front，但 PSP 并非在每个合成场景都最优。因此合成实验适合支持“流程可泛化”，不适合支持“PSP 普遍最优”。

最终真实区域候选：`real_sparse_r04_c40_u130_k10_s1`。

| 项目 | 结果 |
|---|---:|
| Candidate stations | 40 |
| Users | 130 |
| Deployed servers | 10 |
| Stage I CLS cost | 2304.7670 |
| Best initialization baseline cost | 6150.5741 |
| CLS advantage | 62.5276% |

Seed 42 的论文规模 Stage II：

| Method | HV ↑ | IGD ↓ | Best Q ↓ |
|---|---:|---:|---:|
| NS-P | 1.0481 | 0.0193 | 0.2344 |
| GCP | 1.0478 | 0.0263 | 0.2421 |
| GDP | 1.0252 | 0.0405 | 0.2385 |
| PSP | 1.0490 | 0.0192 | 0.2273 |

Seeds 42/43/44 检查中，PSP 三次均取得最优 HV 和 IGD，两次取得最优 Best Q。可写“Pareto 覆盖与收敛质量稳定较好”，不能写“所有指标、所有种子绝对最优”。

### 4.3 两阶段分解与联合优化差距

正式小规模设置：6 candidates、30 users、3 servers、4 service types、capacity 4，seeds 42/43/44。Joint-Exact 穷举服务器组合和服务子集；MOS2-PSP 使用 CLS Stage I 加 PSP Stage II。

| Seed | HV gap | IGD gap | Best Q gap | Joint/MOS2 runtime |
|---:|---:|---:|---:|---:|
| 42 | 6.45% | 0.0289 | 0.0000 | 5.58x |
| 43 | 4.18% | 0.0199 | 0.0000 | 5.89x |
| 44 | 0.98% | 0.0660 | 0.0000 | 6.09x |

三种子平均 HV gap 为 3.87%，Best Q gap 为 0，联合穷举平均约慢 5.85 倍。这是小规模经验结果，不是全局最优性的理论保证。它支持的表述是：两阶段分解显著缩小搜索空间，并在可精确求解的小实例上保持相同的最佳加权折中解和较小的 Pareto 覆盖差距。


仓库内已有 Windows 虚拟环境时可直接使用：

```powershell
.\LocalSearch\Scripts\python.exe -m pip install -r requirements-revision.txt
```

若已有虚拟环境不可跨机器使用，则新建 Python 3.8 环境并安装同一 requirements 文件。

常用命令：

```powershell
# 原有四种 Stage II 方法及指标
.\LocalSearch\Scripts\python.exe .\LocalSearch\batch_service_experiments.py --configs 10_130
.\LocalSearch\Scripts\python.exe .\LocalSearch\pareto_batch_metrics.py --config 10_130

.\LocalSearch\Scripts\python.exe .\LocalSearch\cls_initialization_sensitivity.py --configs all_new --random-runs 50 --seed 42 --max-iter 200

# varpi_j 容量敏感性
.\LocalSearch\Scripts\python.exe .\LocalSearch\hybrid_anchor_sensitivity.py --configs 10_130 10_150 10_180 5_130 15_130 20_130 --capacities 4 8 --varpi-values 1 half 3 Vj --seeds 42 43 44 --pop-size 50 --n-gen 200

# 使用已保存 NPZ 汇总合成泛化结果
```
