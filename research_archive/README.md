# Research Archive Index

Each subdirectory is a date-stamped research snapshot. A snapshot preserves the manuscript, response letter, exact figures, data extracts, and generation tooling used at that point in the project.

| Snapshot | Scope |
|---|---|
| [`2026-07-22_round1`](2026-07-22_round1/README.md) | First journal-review revision package, reviewer-response evidence, DQN/CLS/anchor/joint-gap/generalization experiments, and thesis handoff notes. |

Snapshots are retained for provenance. New development should normally modify the canonical files under `LocalSearch/`, `data/`, `output/`, and `docs/revision/` rather than rewriting an earlier snapshot.
